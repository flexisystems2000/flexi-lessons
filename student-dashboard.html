Account & Data Security

This dashboard is designed to receive student-specific data from a protected backend endpoint. It does not mark payments as verified, calculate an authoritative expiry date from browser storage, or use localStorage registration details as proof of account access. The login endpoint and dashboard-data endpoint must be deployed and configured before live account data can load.
